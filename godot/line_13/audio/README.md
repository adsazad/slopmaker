# Qwen Voice Studio

`narration.txt` is Eli's first-person script. The final voiceover in
`eli_narration.wav` was generated in the project's Qwen Voice Studio using the
`dylan` voice with restrained first-person suspense direction. `eli_narration.srt`
contains sentence-level cues fitted to the generated take. The Godot shot director
loads the WAV and SRT directly.
